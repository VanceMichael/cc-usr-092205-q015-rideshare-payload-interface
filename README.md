# 多星共乘接口交付

协调多颗卫星共乘发射的接口、试验、放行和入轨交付。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实和约束等必要字段。

当前资料反映以下领域事实：

- 力箭一号一次将九颗卫星送入预定轨道
- 载荷包含多个不同名称和研制用途的卫星
- 此次任务是该型火箭第16次飞行
- 任务集成系统以整箭构型为中心，关联每颗星的质量质心、机械边界、供电、遥测、分离序列、禁飞项、联合试验和签署结论
- 某颗星在发射场修改分离参数时，其他研制方最关心自己的包络、时序和遥测窗口是否随之受影响

资料同时约定以下接口交付约束：

- 接口控制文件冻结后，任何豁免都给出适用载荷、截止条件和复验要求
- 卫星替换、测量修正、试验延期、报告重传及倒计时后的撤回不得制造两个有效版本
- 研制方之间只共享接口边界
- 放行会议直接展示尚未闭合的跨载荷冲突和责任单位
- 任务结束后分别核对九颗星的分离与入轨事实，整箭成功不能自动把缺少证据的单星标成已交付

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
